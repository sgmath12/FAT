# Analysis 개편에 대한 정리된 생각

작성일: 2026-09-09

## 1. 논문의 중심 메시지

이 논문의 핵심을 단순히 "natural teacher의 feature를 distill한다"로 두면 ARREST와의
차이가 약해 보일 수 있다. 그러나 ARREST를 Analysis에서 길게 비교하거나 반박할 필요는
없다. Related Work 또는 Introduction에서 다음 차이만 간결하게 고정하면 충분하다.

> ARREST preserves a natural representation as an auxiliary constraint during label-based
> adversarial fine-tuning, whereas CFA uses the clean representation as the sole target for both
> adversarial example generation and backbone training.

CFA의 중심 메시지는 다음과 같이 잡는다.

> Rather than constructing a softened predictive distribution from a natural teacher and balancing
> it against a label loss, CFA directly uses the teacher's clean representation as a fixed target.
> This replaces target calibration and loss balancing with a single feature-space anchor.

즉, CFA에서 중요한 것은 feature라는 layer 자체의 독점적 우월성이 아니라 다음 설계가
하나의 objective로 결합된다는 점이다.

- predictive distribution을 만들기 위한 temperature가 필요하지 않다.
- teacher supervision과 label loss를 결합하기 위한 loss weight가 필요하지 않다.
- teacher의 clean representation이 backbone의 sole supervisory target이 된다.
- adversarial example 생성과 backbone 학습이 동일한 feature discrepancy를 사용한다.
- teacher의 classifier를 그대로 유지하므로 feature target과 prediction이 직접 연결된다.

Frozen-head logit MSE가 feature anchor와 거의 동률이라는 결과는 숨기지 않는다. 이는
feature만 가능하다는 주장이 아니라, temperature-tuned probability matching보다 direct
metric regression이 중요하다는 점을 뒷받침하는 control로 해석한다.

> Direct regression accounts for most of the gain, and CFA instantiates this principle at the
> feature layer, where the teacher's representation remains directly compatible with the inherited
> classifier.

## 2. 권장 Analysis 흐름

### 2.1 Preliminaries

입력 공간, perturbation set, teacher와 student, feature map, classifier를 정의한다. 이후
subsection에서 필요한 notation만 남기고 표준 adversarial training 설명은 짧게 유지한다.

### 2.2 Do Natural Teachers Need Softened Targets?

Robust-teacher distillation에서는 teacher의 soft prediction이 중요한 supervision으로 사용되어
왔다. Natural teacher는 prediction이 매우 confident하므로, 이를 그대로 옮기기 전에 target
softening이 충분한지를 먼저 검사한다.

Teacher-only temperature와 conventional shared-temperature KD를 함께 비교한다. 단순한 sweep으로
보이지 않도록 두 formulation의 gradient와 large-temperature behavior가 다르다는 점을 먼저
설명한다.

- teacher-only temperature는 teacher target만 점차 uniform하게 만든다.
- shared-temperature KD는 student와 teacher를 함께 rescale하며, 적절한 temperature scaling 아래
  high-temperature limit가 centered-logit regression과 연결된다.
- 실험에서는 softening이 robust accuracy를 개선하지만 clean accuracy는 상대적으로 적게 움직인다.
- 따라서 더 좋은 temperature를 찾는 것만으로는 natural teacher가 가진 clean representation을
  충분히 활용하지 못한다.

이 subsection의 결론은 "logit distillation은 실패한다"가 아니다.

> Target softening improves prediction-space distillation, but the limited response on the clean
> axis motivates bypassing the softened distribution and matching the teacher directly in a metric
> space.

### 2.3 A Single Clean Representation as Supervision

이 부분은 길게 쓰지 않는다. ARREST와의 상세 비교나 feature layer에 대한 장황한 정당화도
필요하지 않다. 한 문단으로 predictive distribution에서 clean representation으로 넘어가는
이유를 설명하고, feature anchor 식을 바로 제시한다.

$$
\mathcal L_{\mathrm{anchor}}(x)
=\max_{x'\in B(x,\epsilon)}
\lVert\Phi_s(x')-\Phi_t(x)\rVert_2^2.
$$

식 뒤에서는 다음 세 가지만 설명한다.

1. teacher target은 clean input $x$에서 한 번 계산되어 고정된다.
2. 동일한 discrepancy가 inner maximization과 outer minimization에 사용된다.
3. student backbone만 학습하고 inherited teacher classifier는 고정한다.

Frozen-head logit MSE는 이 subsection의 control로 짧게 보고한다. Feature anchor와의 근소한
차이를 과장하지 않고, direct regression이 temperature-free supervision을 가능하게 한다는
결론만 낸다.

### 2.4 Is an Additional Label Loss Necessary?

Clean feature가 sole target이라는 설계가 임의적인 선택처럼 보이지 않게, label loss를 다시
추가한 sweep을 간결하게 제시한다. 본문의 핵심은 여러 $\lambda$를 모두 나열하는 것이 아니라,
작은 label coefficient에서도 clean--robust balance가 개선되지 않았다는 패턴이다. 자세한 sweep은
Appendix로 보내도 된다.

안전한 결론은 다음과 같다.

> In the evaluated regime, the clean representation is sufficient as the supervisory target;
> adding a ground-truth loss does not improve the clean--robust balance.

"Label loss is generally harmful"처럼 adversarial training 전체로 일반화하지 않는다. 또한
reviewer가 loss-scale 문제를 제기할 수 있으므로, 가능한 경우 매우 작은 $\lambda$와 두 loss의
gradient magnitude를 함께 확인한다.

### 2.5 What the Anchor Controls

앞 subsection에서 길게 설명하지 않은 개념적 역할을 이 부분의 부등식이 담당한다. Clean fidelity
$F$, local student variation $O$, worst-case anchor distance $L$을 정의하고 다음 명제를 제시한다.

$$
L\le F+O\le3L.
$$

이 명제가 담당하는 주장은 제한적이고 명확해야 한다.

- 작은 anchor는 clean feature discrepancy와 within-ball feature variation을 동시에 제한한다.
- 두 항을 별도의 loss로 만들고 coefficient로 balance할 필요가 없다.
- teacher의 perturbed feature가 안정적이라고 가정하지 않는다.
- inherited head 아래에서 feature discrepancy는 logit discrepancy의 upper bound로 연결된다.

반면, 이 명제는 feature가 logit보다 우월하다는 것을 증명하지 않으며 robust classification을
직접 보장하지도 않는다. 이 scope는 짧게 언급하고 상세 내용은 Appendix에 둔다.

### 2.6 What Does Teacher Training Transfer?

Clean representation이 전체 target이라면 어떤 teacher checkpoint를 사용하는지가 학습 결과에
직접 영향을 준다. 이 subsection은 다음 반증 가능한 질문에서 시작한다.

> If CFA merely transfers the teacher's clean accuracy, does a more accurate teacher necessarily
> produce a more accurate student?

Teacher checkpoint ladder는 그 예상과 반대되는 결과를 보인다. Teacher training epoch이 증가하면서
teacher clean accuracy는 상승하지만 student clean accuracy는 감소하며, robust accuracy와 최종
clean--robust operating point도 함께 이동한다. 따라서 teacher accuracy만으로 checkpoint를 고르는
것은 충분하지 않다.

Class-geometry 결과는 이 현상을 해석하는 empirical evidence로 사용한다. 가장 안전한 결론은 다음과
같다.

> Student behavior tracks changes in the teacher's class geometry more closely than changes in the
> teacher's scalar clean accuracy.

현재 증거만으로 class geometry가 유일한 causal mechanism이라고 주장하지 않는다. 핵심 발견은
"better teacher gives a better student"라는 통상적 기대가 깨지고, teacher training length가 CFA의
operating point를 조절한다는 것이다.

## 3. Teacher-epoch 분석에 필요한 추가 실험

### P0: 본문 주장에 필수

#### 3.1 Teacher checkpoint ladder 완성

- 동일한 natural-training trajectory에서 여러 checkpoint를 저장한다.
- 현재의 50--300 epoch 구간뿐 아니라 5, 10, 20, 40 epoch와 같은 weak-teacher 구간까지 포함한다.
- 모든 student는 동일한 architecture, optimizer, schedule, perturbation budget, epoch 수로 학습한다.
- teacher clean accuracy, student Clean, AA, NRR을 동일한 plot에 표시한다.

단순히 가장 흥미로운 구간만 선택하지 말고, 전체 trajectory를 제시해야 post-hoc checkpoint mining
우려를 줄일 수 있다.

#### 3.2 Seed 안정성

- 전체 ladder를 여러 seed로 반복하기 어렵다면 최소한 early, middle, late teacher checkpoint 세 개를
  선택한다.
- 각 checkpoint에서 teacher seed 또는 student-training seed를 3개 이상 평가한다.
- $r=-0.999$ 하나보다 평균, 분산, 순위의 일관성을 주된 근거로 사용한다.

Checkpoint들은 동일 trajectory에서 나온 상관된 관측치이므로 Pearson correlation의 p-value를
독립표본처럼 해석하지 않는다. Pearson/Spearman 값은 descriptive statistic으로만 제시한다.

#### 3.3 Class geometry 정의와 동시 측정

- $S_w/S_b$의 정확한 정의, feature layer, raw/normalized feature 여부, 평균 방식을 명시한다.
- 모든 teacher checkpoint와 그 student에 대해 동일한 protocol로 측정한다.
- clean input과 attack input의 geometry를 분리해서 보고한다.
- scale artifact가 아닌지 확인하기 위해 normalized feature에서도 trend가 유지되는지 검사한다.

본문에는 하나의 primary geometry metric만 사용하고, 추가 metric은 Appendix에 둔다. 가능한 보조
검사로 class-centroid accuracy, normalized margin 또는 linear-probe accuracy 중 하나를 사용할 수 있다.

#### 3.4 Warm-start confound 확인

Teacher checkpoint가 달라지면 target뿐 아니라 student initialization도 함께 달라진다. 따라서
teacher-epoch effect가 단순 initialization 효과가 아님을 확인해야 한다.

- early/middle/late teacher를 골라 teacher initialization과 random initialization을 비교한다.
- target feature와 inherited head는 해당 teacher의 것을 유지하고, student backbone initialization만
  바꾼다.
- 기존 결과처럼 warm start의 영향이 작다면 teacher geometry 해석이 훨씬 강해진다.

### P1: geometry 해석을 강하게 만드는 실험

#### 3.5 비슷한 accuracy, 다른 geometry를 가진 teacher

Training epoch과 teacher accuracy, geometry가 함께 변하면 무엇이 student를 움직이는지 완전히
분리하기 어렵다. 가장 강한 control은 clean accuracy가 유사하지만 geometry가 다른 teacher pair를
구하는 것이다.

- 서로 다른 seed 또는 training recipe에서 clean accuracy가 가까운 checkpoint를 선택한다.
- label smoothing, weight decay 또는 training duration으로 geometry를 변화시키되 teacher accuracy가
  유사한 pair를 구성한다.
- 두 teacher의 student 결과가 accuracy가 아니라 geometry의 순서를 따른다면 핵심 해석이 강해진다.

이 실험은 "geometry causes the change"에 가장 가까운 evidence가 되지만, recipe가 지나치게 달라지면
새로운 confound가 생기므로 하나의 controlled change만 사용하는 것이 좋다.

#### 3.6 Dataset replication

- CIFAR-100에서 전체 ladder를 수행하고, CIFAR-10 또는 Tiny-ImageNet에서 early/middle/late 세 지점을
  반복한다.
- teacher accuracy와 student behavior의 비단조 관계가 데이터셋 하나에만 나타나는지 확인한다.
- 동일한 class-geometry trend가 재현될 때만 일반적인 transfer interpretation으로 확장한다.

### P2: 있으면 좋은 메커니즘 분석

#### 3.7 Target type과 teacher epoch의 interaction

Feature anchor에서 나타나는 teacher-epoch effect가 direct regression 전반의 현상인지 확인한다.

- early/late teacher에서 feature anchor, frozen-head logit MSE, shared-temperature KD를 비교한다.
- 가능하면 middle checkpoint 하나를 추가한다.
- target ranking이 teacher checkpoint에 따라 바뀐다면 "feature is universally best"가 아니라 teacher와
  target parameterization의 interaction으로 해석한다.

현재 50-epoch와 200-epoch 결과는 이미 이러한 interaction을 시사하므로, 전체 target sweep을 모든
checkpoint에서 반복하기보다 대표 checkpoint만 선택하는 편이 효율적이다.

#### 3.8 Feature와 inherited head의 역할 분리

Teacher training 동안 feature geometry와 classifier head가 함께 변한다. 필요하다면 early/late
checkpoint에서 다음을 제한적으로 확인한다.

- 해당 teacher의 feature target과 head를 함께 사용하는 정상 CFA
- 동일 feature target에서 head를 재학습하는 variant
- inherited head를 유지하되 backbone을 random initialization하는 variant

서로 다른 checkpoint의 feature와 head를 무리하게 cross-swap하면 coordinate mismatch가 새로운
confound가 될 수 있으므로, main experiment보다는 diagnostic으로만 사용한다.

## 4. Sensitivity-matched epsilon의 위치와 역할

Sample-wise $\epsilon$은 Analysis에 또 하나의 성능 표로 추가하지 않는다. Analysis 마지막에서
다음 unresolved problem을 제기하고 Method로 넘기는 것이 가장 자연스럽다.

> The preceding analysis specifies what the student should match, but a uniform pixel-space radius
> does not specify how strongly the feature-space anchor is perturbed for each example.

동일한 pixel radius가 sample마다 서로 다른 feature-space loss change를 유발한다는 것을 설명한 뒤,
first-order relation을 제시한다.

$$
\Delta\mathcal L_i\approx\epsilon_i\lVert\nabla_x\mathcal L_i\rVert_1.
$$

Method에서는 fixed total batch budget 아래 이 변화를 equalize하는 radius allocation을 유도하고,
clipping과 실제 $\ell_2$ sensitivity proxy를 정확히 기술한다. Experiments에서는 uniform radius,
randomly permuted allocation, difficulty/margin 기반 allocation과 비교한다.

따라서 teacher epoch과 sample-wise $\epsilon$은 서로 다른 역할을 맡는다.

- teacher epoch: **어떤 geometry가 anchor로 전달되는가**
- sensitivity-matched $\epsilon$: **그 anchor를 sample별로 얼마나 강하게 enforce할 것인가**

## 5. 최종 section 구성

실제 LaTeX에서는 지나치게 많은 subsection을 만들지 않도록 다음처럼 압축한다.

1. **Preliminaries**
2. **Do Natural Teachers Need Softened Targets?**
3. **A Single Clean Representation as Supervision**
   - Direct regression control
   - Role of label supervision
4. **What the Anchor Controls**
5. **What Does Teacher Training Transfer?**

Analysis 마지막 문단에서 uniform input radius와 feature-space sensitivity의 mismatch를 제기한다.
이어지는 Method는 다음 두 subsection으로 구성한다.

1. **Clean Feature Anchoring**
2. **Matching the Perturbation Budget to the Anchor**

이 구성의 전체 논리는 다음과 같다.

> soft target이 필요한가
> $\rightarrow$ clean representation을 직접 사용한다
> $\rightarrow$ label 없이 sole target으로 사용할 수 있는가
> $\rightarrow$ 하나의 anchor가 무엇을 제어하는가
> $\rightarrow$ teacher training이 어떤 representation을 전달하는가
> $\rightarrow$ 그 anchor의 sensitivity에 맞춰 perturbation budget을 배분한다.

이렇게 구성하면 teacher epoch과 sensitivity-matched $\epsilon$이 ARREST와 차별화하기 위해 나중에
추가된 모듈처럼 보이지 않는다. 두 요소 모두 clean representation을 sole adversarial target으로
삼았을 때 자연스럽게 발생하는 후속 문제에 대한 답이 된다.
