\section{Method}
\label{sec:method}

The preceding analysis motivates two design choices for transferring clean
knowledge during adversarial training. First, the clean self-teacher provides
a fixed representation target, allowing the student to preserve the teacher's
clean representation while controlling its variation under perturbations.
Second, even with the teacher fixed, a uniform input-space radius need not
induce a comparable change in the anchoring objective across examples.
Based on these observations, we construct CFA by combining clean feature
anchoring with sample-dependent perturbation budgets. We first describe the
feature-anchoring objective and then introduce a sensitivity-based rule for
allocating the perturbation radius across training examples.


\subsection{Clean Feature Anchoring}
\label{sec:anchor}

We first instantiate the fixed-target principle by using the clean
self-teacher's feature representation as the anchor for adversarial training.
Let \(\Phi_t\) and \(h_t\) denote the frozen feature map and classifier of
the clean self-teacher. The student inherits both,
\(\Phi_s\leftarrow\Phi_t\) and \(h_s=h_t\), after which only \(\Phi_s\)
is optimized.

For a clean example \(x\), CFA solves
\begin{equation}
\begin{aligned}
x_{\mathrm{adv}}
&=
\operatorname*{arg\,max}_{x'\in B(x,\epsilon)}
\lVert\Phi_s(x')-\Phi_t(x)\rVert_2^2,\\
\mathcal L_{\mathrm{CFA}}
&=
\mathbb E_x
\left[
\lVert\Phi_s(x_{\mathrm{adv}})-\Phi_t(x)\rVert_2^2
\right].
\end{aligned}
\label{eqn:anchor}
\end{equation}

We approximate the inner maximization with randomly initialized PGD against
the fixed clean target \(\Phi_t(x)\) and minimize the same discrepancy over
the student backbone. This adversarial-training stage uses no label loss,
while inference uses \(h_t\circ\Phi_s\).
\Cref{alg:cfa} summarizes the complete procedure.


\subsection{Sensitivity-Matched \(\epsilon\)}
\label{sec:angeps}

The anchoring objective above still leaves the perturbation radius to be
specified. A uniform pixel radius gives every example the same input-space
budget, but does not account for how strongly the anchor loss responds to
that perturbation. We therefore allocate the perturbation budget according
to the local sensitivity of the anchoring objective. The mean radius within
each batch is kept fixed, so the procedure redistributes rather than
increases the overall training budget.

For
\[
\ell_{\mathrm{anc}}(x';x_i)
=
\lVert
\Phi_s(x')-\Phi_t(x_i)
\rVert_2^2,
\]
consider its first-order change around the clean input \(x_i\). Under an
\(\ell_\infty\) perturbation of radius \(e\),
\begin{equation}
\max_{\lVert\delta\rVert_\infty\le e}
\left\langle
\nabla_{x'}
\ell_{\mathrm{anc}}(x';x_i)\big|_{x'=x_i},
\delta
\right\rangle
=
e
\left\lVert
\nabla_{x'}
\ell_{\mathrm{anc}}(x';x_i)\big|_{x'=x_i}
\right\rVert_1.
\label{eqn:firstorder}
\end{equation}
Thus, the local increase in anchor loss scales with both the perturbation
radius and the sensitivity of the anchoring objective.

Motivated by this relation, let \(g_i>0\) denote a local sensitivity score
for example \(x_i\). We assign smaller perturbation radii to more sensitive
examples and larger radii to less sensitive ones according to
\begin{equation}
\epsilon_i
=
N\epsilon
\frac{g_i^{-p}}
{\sum_{j=1}^{N} g_j^{-p}},
\label{eqn:angeps_ideal}
\end{equation}
where \(N\) is the batch size and \(\epsilon\) is the mean perturbation
radius. The exponent \(p\) controls the strength of sensitivity matching:
\(p=0\) recovers a uniform radius, while larger \(p\) increasingly allocates
smaller radii to more sensitive examples.

By construction,
\[
\sum_{i=1}^{N}\epsilon_i=N\epsilon,
\]
so sensitivity matching changes only how the perturbation budget is
distributed across examples, rather than the average strength of adversarial
training. Unlike sample weighting in the outer objective, this allocation
changes the perturbation neighborhood assigned to each example while
retaining equal weight for each example in the training average.

The first-order relation in \Cref{eqn:firstorder} motivates sensitivity as
the quantity governing radius allocation, rather than asserting that the
resulting nonlinear adversarial losses are exactly equalized. The key
empirical question is therefore whether sensitivity provides a useful
assignment of the perturbation budget. Accordingly, \Cref{tab:allocation}
compares sensitivity matching with a uniform radius and alternative
assignment rules, including a control that preserves the same multiset of
sensitivity-derived radius multipliers but reassigns them according to
sample difficulty. If the gain arises merely from introducing heterogeneous
radii, this reassignment should preserve the improvement; otherwise, which
example receives each radius matters.
