\section{Method}
\label{sec:method}

CFA combines a clean-feature training objective with sample-dependent perturbation budgets. The
chosen teacher fixes the reference representation; radius allocation determines the neighborhood
over which each example is trained to preserve it.

\subsection{Clean Feature Anchoring}
\label{sec:anchor}

Let $\Phi_t$ and $h_t$ be the frozen feature map and classifier of the natural teacher. The student
inherits both, $\Phi_s\leftarrow\Phi_t$ and $h_s=h_t$, after which only $\Phi_s$ is optimized. For a
clean example $x$, CFA solves
\begin{equation}
\begin{aligned}
x_{\mathrm{adv}}
&=\operatorname*{arg\,max}_{x'\in B(x,\epsilon)}
  \lVert\Phi_s(x')-\Phi_t(x)\rVert_2^2,\\
\mathcal L_{\mathrm{CFA}}
&=\mathbb E_x\!\left[\lVert\Phi_s(x_{\mathrm{adv}})-\Phi_t(x)\rVert_2^2\right].
\end{aligned}
\label{eqn:anchor}
\end{equation}
We approximate the inner maximization with randomly initialized PGD against the fixed target
$\Phi_t(x)$ and minimize the same discrepancy over the backbone. This adversarial-training stage
uses no label loss; inference uses $h_t\circ\Phi_s$. \Cref{alg:cfa} gives the complete procedure.

\subsection{Sensitivity-Matched $\epsilon$}
\label{sec:angeps}

A uniform pixel radius gives every example the same input-space budget, but not the same potential
increase in anchor loss. We therefore allocate radii using the local sensitivity of the objective
used for both attack generation and student training. The batch's mean radius remains fixed; only
its assignment across examples changes. For
$\ell_{\mathrm{anc}}(x';x_i)=\lVert\Phi_s(x')-\Phi_t(x_i)\rVert_2^2$, define
\begin{equation}
g_i=\left.\lVert\nabla_{x'}\ell_{\mathrm{anc}}(x';x_i)\rVert_1\right|_{x'=x_i},
\qquad
\max_{\lVert\delta\rVert_\infty\le e}
\langle\nabla_{x'}\ell_{\mathrm{anc}},\delta\rangle=e g_i.
\label{eqn:firstorder}
\end{equation}
The linearized worst-case loss increase under radius $\epsilon_i$ is therefore $\epsilon_i g_i$.
To keep this local increase comparable across examples, a more sensitive example should receive
a smaller radius. For $g_i>0$, equalizing the products subject to
$\sum_i\epsilon_i=N\epsilon$ gives
\begin{equation}
\epsilon_i=N\epsilon\frac{g_i^{-1}}{\sum_jg_j^{-1}},
\qquad\text{or more generally}\qquad
\epsilon_i\propto g_i^{-p},
\label{eqn:angeps_ideal}
\end{equation}
where $p=0$ recovers a uniform radius and $p=1$ gives inverse-sensitivity allocation.
The conserved sum separates redistribution from a change in the mean training budget. Unlike a
sample-weighted outer loss, this rule changes the perturbations seen during training without
changing the coefficient of each example in the training average. It is a local approximation to
loss growth, not a claim that nonlinear adversarial losses become equal.

We implement $p=1$ with an $\ell_2$ gradient norm, measured by one backward pass at the clean input.
The $\ell_1$ norm follows exactly from the linearized $\ell_\infty$ problem, but the $\ell_2$ proxy
performs slightly better here (\Cref{app:box}). Thus the first-order argument motivates the rule
without uniquely determining its implementation. Clipping and renormalization preserve the batch
budget, and PGD step sizes scale with the assigned radii; implementation details are in
\Cref{app:box}.
The key test is whether sensitivity assigns the budget usefully, not merely whether varying radii
helps. Accordingly, \Cref{tab:allocation} compares uniform and alternative signals, including a
control that keeps the exact multiset of sensitivity-derived multipliers but assigns them by sample
difficulty. If the spread of radii alone explains the gain, this reassignment should preserve it;
otherwise, which example receives each radius matters.
