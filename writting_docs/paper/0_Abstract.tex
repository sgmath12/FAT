\begin{abstract}
Robust distillation commonly treats supervision as a predictive distribution whose softness and
weight must be chosen. We ask whether a naturally trained teacher can instead supervise adversarial
training through one fixed clean target, without a label objective. Clean Feature Anchoring (CFA)
instantiates this principle by matching the student's adversarial feature to the teacher's clean
feature while keeping the inherited classifier fixed. A matched clean-logit control reaches a
similar endpoint, indicating that direct clean-target regression, rather than a uniquely privileged
feature metric, is the broader mechanism. For the feature realization, we show that one anchor
jointly controls clean teacher fidelity and local feature variation. We then allocate a fixed batch
budget of attack radii according to the anchor loss's input sensitivity. Across three runs of the
final CIFAR-100 recipe, this raises clean accuracy by $2.19$ points on average while leaving
AutoAttack accuracy unchanged. CFA attains $64.82\mathbin{\pm}0.07\%$ clean and
$28.04\mathbin{\pm}0.09\%$ AutoAttack accuracy on CIFAR-100 with ResNet-18, with strong results
also on CIFAR-10 and Tiny-ImageNet.
\end{abstract}
